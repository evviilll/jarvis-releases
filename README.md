# Jarvis — releases

Public download mirror for the Jarvis voice assistant (Windows 10/11).
Source code lives in a private repository; this repo contains only installers.

- Download `JarvisSetup-x.y.z.exe` from [Releases](https://github.com/evviilll/jarvis-releases/releases/latest).
- Every installer has a `.sha256` file; Jarvis verifies it before auto-updating.
- Installed Jarvis checks this repo on start and every 6 hours and updates itself (no token needed).
